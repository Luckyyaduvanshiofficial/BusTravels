## 📱 MOBILE vs DESKTOP

- Multi-column layouts

**Mobile:**
- Bottom tab bar (64px)
- Single column layouts

- Hamburger menu

---

## 🎨 KEY DESIGN PATTERNS

**Color Usage:**
- Orange: Primary actions, active states
- Blue: Links, information, trust
- Green: Success, confirmed bookings
- Yellow: Pending, warnings
- Red: Errors, cancellations

**Typography Hierarchy:**
- Page headings: 40px/28px (desktop/mobile) Poppins Bold
- Section headings: 24px Poppins Semibold
- Body text: 16px Inter Regular
- Small text: 14px Inter Regular

**Spacing:**
- Card padding: 24px
- Section gaps: 48px
- Button padding: 12px vertical, 24px horizontal
- All follows 8px grid

**Components:**
- Buttons: 48px height (mobile), 44px (desktop)
- Cards: 12px-16px border radius, subtle shadows
- Inputs: 56px height, 12px border radius
- Status badges: Pill shape, colored backgrounds
